# Журнал изменений

Что менялось в FrogWord. Проект в альфе и версий пока не выпускает: записи идут по датам
публикации на GitHub, сверху — то, что ещё не опубликовано.

## 01.10.2026

- Лицензия MIT: `LICENSE` и неофициальный перевод `LICENSE_RU.md`. Что взято со стороны и на
  каких условиях — `THIRD-PARTY-NOTICES.md`, порядок правок — `CONTRIBUTING.md`.
- Значки приложения и веб-версии — из набора Klaarheid Icons (MIT-0) вместо библиотеки
  Lucide; пакет `lucide-react` больше не нужен.
- Фоновые лягушки веб-версии нарисованы заново, из отрезков и дуг (`npm run frogs`): прежние
  силуэты были значками ICOOON MONO, а их правила запрещают распространять значки.
- Лягушка-маскот (эмодзи из Noto Emoji) вынесена в отдельный модуль — с пометкой об
  изменениях и текстом лицензии Apache 2.0 рядом. Рядом со шрифтом Cygre лежит его
  лицензионное соглашение.
- Веб-версия и окно приложения несут тексты лицензий в папке `licenses/`: лицензия FrogWord,
  лицензии пакетов npm из сборки, маскота и шрифта.
- `npm run check` — стражи: внешние адреса, значки, лягушки, лицензии рядом с чужими файлами и
  лицензии библиотек. Проверка на GitHub прогоняет типы, тесты, стражей и сверяет `docs/` с
  пересборкой.
- Веб-версия в `docs/` пересобрана; лишние файлы прежних сборок убраны.
- README больше не ссылается на файлы, которых нет в репозитории.

## 26.07.2026

  к букве: следующая буква достижима из предыдущей одним ходом.
- Исходники веб-версии — в репозитории, сборка — `npm run build:pages`.

  авторизации стримера.
